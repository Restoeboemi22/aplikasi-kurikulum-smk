# Panduan Penggunaan Menu Guru

Dokumen ini disusun sebagai bahan presentasi penggunaan aplikasi untuk akun guru.
Isi panduan mengikuti perilaku aplikasi saat ini dan dibagi menjadi dua profil:

1. Guru biasa
2. Guru yang merangkap wali kelas

## 1. Tujuan Panduan

Panduan ini membantu menjelaskan:

- menu apa saja yang muncul pada akun guru
- perbedaan menu guru biasa dan guru wali kelas
- langkah penggunaan tiap menu
- output yang dihasilkan dari setiap menu

## 2. Profil Akses Guru

### 2.1 Guru Biasa

Guru biasa dapat menggunakan menu yang terkait langsung dengan tugas mengajar, yaitu:

- Dashboard
- Kurikulum
  - Perangkat Pembelajaran
  - Perangkat Penilaian
- Jadwal
  - Jadwal Piket Kelas
  - Jadwal Piket Keagamaan
- Jurnal
  - Jurnal Mengajar
- Penilaian
  - TP (Tujuan Pembelajaran)
  - AH (Asesmen Harian)
  - Tugas
  - STS
  - SAS
  - Nilai Sikap

### 2.2 Guru yang Merangkap Wali Kelas

Guru wali kelas mendapatkan semua menu guru biasa, ditambah:

- Penilaian
  - Master Nilai
- Laporan
  - Cetak Raport TKJ/TKR STS
  - Cetak Raport TKJ/TKR SAS

Catatan:

- menu raport hanya muncul sesuai jurusan kelas wali yang diampu
- jika wali kelas TKJ, maka menu raport TKJ yang muncul
- jika wali kelas TKR, maka menu raport TKR yang muncul
- jika memegang lebih dari satu kelas dalam jurusan yang sama, kelas akan dipilih dari filter pada halaman raport

## 3. Menu yang Tidak Muncul di Akun Guru

Secara umum, akun guru tidak menggunakan menu administrasi inti, seperti:

- Database
- Kelola Akun
- Pengaturan
- Dokumen admin lain yang khusus verifikasi/monitoring tingkat admin

Beberapa halaman memang ada di aplikasi, tetapi tidak ditampilkan ke guru karena dipakai untuk kebutuhan admin.

## 4. Alur Umum Penggunaan Akun Guru

Urutan penggunaan yang paling mudah dijelaskan saat presentasi:

1. Guru login ke aplikasi
2. Guru membuka menu sesuai tugas hari itu
3. Guru mengisi data atau mengunggah dokumen
4. Guru menyimpan data
5. Data masuk ke monitoring admin atau dipakai untuk proses raport

## 5. Detail Penggunaan Tiap Menu

## 5.1 Dashboard

### Fungsi

Halaman pembuka akun guru setelah login.

### Kegunaan

- memastikan akun guru berhasil masuk
- melihat identitas pengguna yang sedang aktif
- menjadi titik awal menuju menu lain

### Cara Menggunakan

1. Login menggunakan akun guru
2. Setelah berhasil masuk, sistem menampilkan dashboard guru
3. Gunakan sidebar kiri untuk berpindah ke menu kerja

### Catatan Presentasi

Saat demo, cukup jelaskan bahwa halaman ini adalah beranda guru dan bukan tempat input data utama.

## 5.2 Kurikulum - Perangkat Pembelajaran

### Fungsi

Digunakan guru untuk mengirim file perangkat pembelajaran ke sistem.

### Tujuan

- mengunggah dokumen perangkat pembelajaran
- menyimpan riwayat pengumpulan
- memudahkan admin melihat dan mengunduh file yang sudah dikirim

### Alur Guru

Pada akun guru, fokus utamanya adalah tab submit/pengiriman perangkat.

### Langkah Penggunaan

1. Buka menu `Kurikulum > Perangkat Pembelajaran`
2. Pilih data perangkat yang akan dikirim
3. Lengkapi informasi yang diminta
4. Unggah file dokumen
5. Klik tombol simpan/kirim
6. Pastikan data masuk ke daftar riwayat pengiriman

### Hasil

- file tersimpan di sistem
- admin dapat melakukan pengecekan
- dokumen dapat diunduh kembali bila sudah tersimpan

### Poin Penting Untuk PPT

- guru tidak perlu mengelola verifikasi admin
- fokus guru hanya pada pengumpulan dokumen yang benar dan lengkap

## 5.3 Kurikulum - Perangkat Penilaian

### Fungsi

Digunakan guru untuk mengirim file perangkat penilaian.

### Langkah Penggunaan

1. Buka menu `Kurikulum > Perangkat Penilaian`
2. Isi data perangkat penilaian
3. Unggah file
4. Simpan pengiriman
5. Pastikan file muncul pada daftar riwayat

### Hasil

- perangkat penilaian tercatat
- admin dapat melihat status pengumpulan
- file dapat dibuka atau diunduh kembali jika tersedia

### Catatan

Secara konsep sama dengan perangkat pembelajaran, hanya beda jenis dokumen yang dikirim.

## 5.4 Jadwal - Jadwal Piket Kelas

### Fungsi

Digunakan untuk pelaksanaan piket kelas oleh guru yang mendapat jadwal.

### Tujuan

- melihat jadwal piket yang menjadi tugas guru
- mengisi laporan pelaksanaan piket
- memastikan kegiatan piket terdokumentasi

### Langkah Penggunaan

1. Buka menu `Jadwal > Jadwal Piket Kelas`
2. Cari jadwal yang sesuai hari/tanggal tugas
3. Buka data jadwal yang menjadi tanggung jawab guru
4. Isi laporan atau status pelaksanaan piket
5. Simpan laporan ke server

### Hasil

- status piket tercatat
- admin dapat memonitor pelaksanaan

### Catatan Presentasi

Jelaskan bahwa tampilan guru berbeda dengan admin. Guru fokus pada pelaksanaan, sedangkan admin fokus pada penyusunan dan monitoring jadwal.

## 5.5 Jadwal - Jadwal Piket Keagamaan

### Fungsi

Digunakan untuk pelaksanaan dan pelaporan piket keagamaan.

### Langkah Penggunaan

1. Buka menu `Jadwal > Jadwal Piket Keagamaan`
2. Temukan jadwal yang menjadi tanggung jawab guru
3. Isi laporan pelaksanaan
4. Simpan hasil laporan

### Hasil

- aktivitas piket keagamaan terdokumentasi
- admin dapat memantau guru yang sudah atau belum melaksanakan piket

## 5.6 Jurnal - Jurnal Mengajar

### Fungsi

Digunakan guru untuk mengisi jurnal kegiatan belajar mengajar.

### Data yang Diisi

- nama guru
- mata pelajaran
- kelas
- tanggal
- semester
- tahun ajaran
- jam ke-
- materi pembelajaran
- jumlah hadir
- jumlah tidak hadir
- catatan/kendala
- daftar siswa yang tidak hadir

### Langkah Penggunaan

1. Buka menu `Jurnal > Jurnal Mengajar`
2. Pilih guru, mapel, dan kelas sesuai penugasan
3. Tentukan tanggal, semester, dan tahun ajaran
4. Pilih jam ke- yang diajar
5. Isi materi pembelajaran
6. Tandai kehadiran siswa pada tabel presensi
7. Tambahkan catatan atau kendala bila diperlukan
8. Klik `Simpan Jurnal`

### Hasil

- jurnal tersimpan di sistem
- data ketidakhadiran siswa ikut terbentuk dari jurnal ini
- jurnal dapat dipakai sebagai dasar monitoring pembelajaran

### Poin Penting

- presensi siswa pada jurnal berpengaruh ke laporan ketidakhadiran
- guru harus mengisi data secara lengkap agar rekap admin akurat

## 5.7 Penilaian - TP (Tujuan Pembelajaran)

### Fungsi

Digunakan untuk mengelola tujuan pembelajaran yang menjadi dasar penilaian.

### Langkah Penggunaan

1. Buka menu `Penilaian > TP (Tujuan Pembelajaran)`
2. Pilih kelas, mapel, dan periode yang sesuai
3. Tambahkan atau sesuaikan tujuan pembelajaran
4. Simpan data

### Hasil

- tujuan pembelajaran tersimpan
- tujuan ini menjadi acuan input nilai pada menu penilaian

## 5.8 Penilaian - AH (Asesmen Harian)

### Fungsi

Digunakan untuk memasukkan nilai asesmen harian.

### Langkah Penggunaan

1. Buka menu `Penilaian > AH`
2. Pilih kelas, mata pelajaran, semester, dan tahun ajaran
3. Pastikan daftar siswa sesuai kelas yang diajar
4. Isi nilai AH
5. Simpan nilai

### Hasil

- nilai harian tersimpan
- data dipakai pada rekap nilai dan raport

## 5.9 Penilaian - Tugas

### Fungsi

Digunakan untuk mengisi nilai tugas siswa.

### Langkah Penggunaan

1. Buka menu `Penilaian > Tugas`
2. Pilih kelas, mapel, semester, dan tahun ajaran
3. Isi nilai tugas tiap siswa
4. Simpan data

### Hasil

- nilai tugas masuk ke rekap akademik
- nilai tugas ikut terbaca pada master nilai dan raport

## 5.10 Penilaian - STS

### Fungsi

Digunakan untuk mengisi nilai Sumatif Tengah Semester.

### Langkah Penggunaan

1. Buka menu `Penilaian > STS`
2. Pilih kelas, mapel, semester, dan tahun ajaran
3. Isi nilai STS
4. Simpan data

### Hasil

- nilai STS tersimpan
- nilai masuk ke proses rekap dan raport

## 5.11 Penilaian - SAS

### Fungsi

Digunakan untuk mengisi nilai Sumatif Akhir Semester.

### Langkah Penggunaan

1. Buka menu `Penilaian > SAS`
2. Pilih kelas, mapel, semester, dan tahun ajaran
3. Isi nilai SAS
4. Simpan data

### Hasil

- nilai SAS tersimpan
- nilai ikut terbaca ke rekap raport

## 5.12 Penilaian - Nilai Sikap

### Fungsi

Digunakan untuk memasukkan nilai sikap siswa.

### Langkah Penggunaan

1. Buka menu `Penilaian > Nilai Sikap`
2. Pilih kelas, semester, dan tahun ajaran
3. Isi nilai sikap sesuai penilaian guru
4. Simpan data

### Hasil

- nilai sikap tersimpan di sistem
- data dapat digunakan pada rekap dan raport siswa

## 5.13 Penilaian - Master Nilai

### Akses

Menu ini hanya muncul untuk guru yang merangkap wali kelas.

### Fungsi

Digunakan untuk melihat rekap seluruh nilai siswa pada kelas yang diampu wali kelas.

### Fitur Utama

- filter kelas
- filter semester
- filter tahun ajaran
- filter mata pelajaran
- tampilan rekap nilai per siswa
- download excel

### Langkah Penggunaan

1. Buka menu `Penilaian > Master Nilai`
2. Pilih kelas wali yang ingin dilihat
3. Pilih semester dan tahun ajaran
4. Pilih mata pelajaran tertentu atau tampilkan semua mata pelajaran
5. Tinjau rekap nilai siswa
6. Jika dibutuhkan, klik `Download Excel`

### Hasil

- wali kelas dapat memeriksa kelengkapan nilai seluruh siswa
- data membantu pengecekan sebelum cetak raport

### Catatan

- akun guru wali kelas hanya melihat kelas asuhnya sendiri
- wali kelas tidak melihat seluruh kelas seperti admin

## 5.14 Laporan - Cetak Raport STS/SAS

### Akses

Menu ini hanya muncul untuk guru yang merangkap wali kelas.

### Fungsi

Digunakan untuk melihat preview raport dan mengunduh PDF raport siswa pada kelas asuh.

### Variasi Menu

- Cetak Raport TKJ - STS
- Cetak Raport TKJ - SAS
- Cetak Raport TKR - STS
- Cetak Raport TKR - SAS

### Fitur Utama

- filter semester
- filter tahun ajaran
- filter kelas
- filter siswa
- tombol `Tampilkan Preview`
- tombol `Download PDF`
- tombol `Finalisasi Raport`
- tombol `Simpan Data Pelengkap`

### Langkah Penggunaan

1. Buka menu raport sesuai jurusan dan jenis laporan
2. Pilih semester dan tahun ajaran
3. Pilih kelas wali
4. Pilih nama siswa
5. Klik `Tampilkan Preview`
6. Periksa hasil raport
7. Lengkapi data pelengkap raport bila diperlukan
8. Klik `Simpan Data Pelengkap`
9. Jika sudah benar, gunakan `Finalisasi Raport`
10. Klik `Download PDF` untuk mengunduh hasil raport

### Hasil

- wali kelas dapat mengecek isi raport sebelum dibagikan
- raport dapat diunduh dalam bentuk PDF

### Catatan

- format rapport STS dan SAS memakai halaman raport terbaru
- kota dan tanggal raport berlaku per kelas pada data pelengkap raport

## 6. Tips Saat Presentasi PPT

Supaya presentasi guru lebih mudah dipahami, urutan slide yang disarankan:

1. Tujuan aplikasi untuk guru
2. Perbedaan akses guru biasa dan wali kelas
3. Dashboard dan alur navigasi sidebar
4. Menu Kurikulum
5. Menu Jadwal
6. Menu Jurnal Mengajar
7. Menu Penilaian
8. Menu tambahan untuk wali kelas
9. Alur akhir: input guru -> rekap nilai -> raport

## 7. Contoh Narasi Presentasi Singkat

Contoh narasi yang bisa dipakai saat menjelaskan:

> Akun guru digunakan untuk kegiatan operasional harian, mulai dari pengumpulan perangkat, pengisian jurnal, hingga input nilai.  
> Jika guru juga merangkap wali kelas, maka sistem otomatis menampilkan menu tambahan seperti Master Nilai dan Cetak Raport sesuai kelas yang diampu.  
> Dengan demikian, hak akses guru tetap terjaga, namun kebutuhan wali kelas tetap terpenuhi dalam satu akun yang sama.

## 8. Penutup

Inti penggunaan akun guru:

- guru mengisi data pembelajaran dan penilaian
- wali kelas memeriksa rekap dan raport
- admin tetap menjadi pengelola utama tingkat sistem

Dokumen ini dapat dipakai langsung sebagai dasar pembuatan slide presentasi penggunaan akun guru.
